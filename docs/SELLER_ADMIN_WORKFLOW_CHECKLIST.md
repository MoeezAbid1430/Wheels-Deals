# Seller And Admin Workflow Checklist

## Seller Workflow

### Draft And Submission

- Save draft automatically.
- Show listing completeness score.
- Validate required fields by listing type.
- Detect duplicate VIN/chassis and duplicate photos.
- Add AI price guidance.
- Add AI reserve recommendation for auction.
- Add document checklist.
- Add media quality checklist.
- Support car listing, auction listing, and accessory listing.

### Seller Dashboard

- Active listings.
- Active auctions.
- Accessory inventory.
- Drafts.
- Pending admin review.
- Rejected/requested changes.
- Leads/messages.
- Saves/views/watchers.
- Bids and highest bidder status.
- Checkout and handover status.
- Payout and settlement status.

### Seller Analytics

- Listing views.
- Search appearances.
- Saves/watchlist.
- Message conversion.
- Bid velocity.
- Auction heat.
- Price competitiveness.
- Recommended listing improvements.

## Admin Workflow

### Review Queues

- Seller submissions.
- Auction approvals.
- Accessory approvals.
- KYC review.
- Document verification.
- Fraud/risk queue.
- Reported posts/comments.
- User reports.
- Payment/withdrawal review.
- Disputes.

### Listing Review

- Verify VIN/chassis.
- Verify title and ownership.
- Verify seller identity.
- Check duplicate listing.
- Check image quality and manipulation.
- Check price/reserve reasonableness.
- Check prohibited items.
- Approve, reject, or request changes.

### Auction Control

- Start auction.
- Pause auction.
- End auction.
- Reopen auction.
- Edit reserve before launch.
- View bid audit trail.
- Flag suspicious bids.
- Mark winner default.
- Trigger second-chance offer.
- Monitor checkout status.

### Trust And Safety

- Risk score per user.
- Risk score per listing.
- Risk score per bid.
- Device/IP overlap.
- Repeated bid withdrawals.
- Fake seller detection.
- Spam/community moderation.
- Suspension and appeal workflow.

### Audit Logs

- Admin action logs.
- Seller status changes.
- Listing edits.
- Bid changes.
- Payment webhooks.
- KYC decisions.
- Dispute decisions.
